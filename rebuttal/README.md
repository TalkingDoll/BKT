# Experiments added during the ICLR 2027 discussion

`BKT_rebuttal_experiments.ipynb` contains the code of the experiments added in the revision (LAWGD with the same eigenpairs, a coupled three-dimensional double well with jointly estimated eigenpairs, a barrier-height scan with trajectory data, and two well-separated Gaussian mixtures with estimated eigenpairs and with the exact eigenfunction), the result files embedded as data, and the tables and the figure computed from them. Running the notebook from the top writes the library and the scripts next to it, writes the embedded results to `results/`, and recomputes the tables and the figure in a few seconds. Each experiment script is then run from a terminal in the same folder, as described in the notebook.

| Path | Contents |
|---|---|
| `results/` | Result files of the runs reported in the paper (also embedded in the notebook) |
| `figures/` | Figure 8 of the paper |
